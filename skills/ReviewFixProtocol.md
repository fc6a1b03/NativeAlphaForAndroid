> 权威源分工：编码规范见 `skills/GoogleCodingStandards.md`（R1-R12），
> **流程纪律在本文件**——两者互不复制，互为引用。`AGENTS.md` 坑位记录
> 事故现场，本文件把事故教训协议化为「阶段 + 不变量 + 记账」。
>
> 适用范围：任何修复、重构、兼容性改动与对外发版。简单单行修改可跳过
> 阶段展开，但不变量不豁免。

## 阶段流（六阶段，逐阶段记账）

```
S1 诊断 → S2 查现成方案 → S3 方案 → S4 实现 → S5 验证 → S6 发版门
```

**S1 诊断**：逐字读失败信号；读失败位置原始上下文（源码 50 行级，非摘要）；
用工具核实全部前置假设（版本/路径/权限/依赖）；输出一句绑定证据的诊断
（「问题是 X；证据是 Y；下一步动作是 Z」）。未走完本阶段禁止改代码。

**S2 查现成方案**：动手前先查——官方源码与文档（Chromium/androidx/Android
平台）、GitHub 同类开源实现、既有仓库先例（AGENTS 坑位）。六版反复翻车的
共同起点都是跳过本阶段（v2.4.12-14 案例：先读 Chromium `Document::ThemeColor`
源码可一步到位的判据，靠试错烧了三版）。

**S3 方案**：写清「改哪里/不改哪里/为什么够」；判定逻辑下沉 Kotlin 纯函数
（可 JVM 穷举单测——「JS 判定不可单测」是 v2.4.15 重构根治的结构性翻车源）；
新方案 = 全量重构，旧逻辑与废逻辑必须清干净（配防丢失契约单测，见不变量 N2）。

**S4 实现**：按规范执行（编码规范见 GCS）；重构期间契约单测先行；改源后
必须 `assembleDebug` 产出新包——**只跑 testDebugUnitTest 不产 APK，真机
实验会拿旧包空转**（handoff 事故 3 实锤，两轮实验浪费）。

**S5 验证**：见验证矩阵。任何「应该没问题」不得替代实际运行。

**S6 发版门**：验证完整前禁止发版（用户红线）；tag 必须打 dev 线版本提交
（merge commit 污染 Release 区间，v2.4.10 实锤）；Release body 是对外产物，
发布前逐条读；发版文档同步（README+AGENTS 页脚）先行。

## 不变量（N1-N8，任何阶段不得违反）

- **N1 候选信号 ≠ 结论**：探针只证明「应用了什么值」，**像素才证明用户所见**
  （坑位 16：targetSdk 35+ 栏色赋值 no-op、SelfManagedInsets 下页面透出与
  着色像素不可分——判别须 display:none 强制透出或图标亮暗翻转）。单一信号
  不定谳，双轨（探针+像素）闭环。
- **N2 重构防丢失**：新方案全量重构时，旧逻辑的每一块（尤其补丁型逻辑如
  样式表 load 监听）必须有契约单测钉住再动手——link-load 块曾在重构中被
  Write 覆盖丢失（handoff 事故 2）。
- **N3 构建产物同步**：改源必须 assembleDebug；dex 字符串验证（`__wnBound`
  0 hits）是产物过期的定谳手法。
- **N4 验证前置**：验证完整前禁止发版；「模拟器绿」不等于「实机绿」
  （WebView 131 内核怪癖模拟器 137 测不出——栏色改动一律真机 debug 包
  CDP+像素回归）。
- **N5 实机纪律**：真机只读优先；UI 自动化先申报再动；禁复现「错误页+
  站点切换」序列（登出事故教训，Cookie 快照竞争候选）；系统设置先读原值、
  测完恢复。
- **N6 性能红线**：WebView 注入脚本事件驱动、observer 只收窄范围（html 自身
  +head）、getComputedStyle 仅低频回调、禁止轮询与全页 subtree 监听；
  方案附性能预算表。
- **N7 量化不猜**：体感类反馈（延迟/卡顿/不跟随）用 CDP spy 毫秒级时间线
  量化，不凭「感觉变快了」收工。
- **N8 通用兼容**：修复不得逐站写适配（用户定调「不要得一个网站就得做
  兼容一次」）——判据必须是通用语义（页面声明/背景渲染），不是站点名单。

## 验证矩阵（S5 展开项，按改动类型选择）

| 改动类型 | 必跑 |
|---|---|
| 任何 Kotlin/资源改动 | `testDebugUnitTest lintDebug` 全绿 |
| 动了源码且需真机验证 | `assembleDebug` 后确认包内符号（dex grep） |
| WebView 注入脚本改动 | 真机 debug 包 CDP + 像素回归（模拟器仅逻辑回归） |
| 系统栏/主题类 | 像素 + `colorScheme`/`matchDark` 联合读值，探针仅辅助 |
| 矩阵/多窗类 | 后台回收 + pauseTimers 配对 + 崩溃恢复路径 |
| 发版 | 全回归矩阵 + Release body 逐条验收 + aapt 抽验 versionCode |

## 记账制

每阶段输出三行账：**已验证事实 / 已排除可能 / 下一步**。账未闭环不得宣布
完成——「候选完成 + 证据链 + 剩余风险」是交付口径，自测通过不等于验收。
失败两次同思路 = 原地打转，强制换本质不同的方案并列 3 个假设再动手。
